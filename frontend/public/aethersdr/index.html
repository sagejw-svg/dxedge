ABOUT AETHERSDR INFO
AetherSDR is a Linux-native client for FlexRadio Systems transceivers, built in Qt6 / C++20, that speaks the SmartSDR protocol natively — no Wine, no VM. Also runs on macOS and Windows. v26.6.3
License
GPL-3.0
Firmware
SmartSDR 4.x
Radios
FLEX-6000 / 8000 / Aurora
Platforms
Linux · macOS · Windows
  • GPU spectrum & waterfall via Qt RHI — multi-slice, multi-panadapter
  • Aetherial Audio Channel Strip — unified RX/TX DSP (EQ, compressor, de-esser, reverb, limiter)
  • Six noise-reduction engines plus DAX virtual audio + IQ (4 RX + 1 TX)
  • AetherModem packet radio (KISS-over-TCP) + APRS support
  • AetherSweep built-in SWR analyzer
  • SpotHub aggregates DX Cluster, RBN, WSJT-X, POTA, FreeDV Reporter
  • CW operator suite with real-time Morse decoder
  • FreeDV RADE digital voice
  • SmartLink remote + TCI v2.0 server
  • Hardware control — rigctld, MIDI, FlexControl, Stream Deck, serial PTT/CW
