Old iron, new tab

A curated catalogue of computers, calculators, minicomputers, CPUs, circuits, fractals, signal and physics simulations that run entirely inside your browser. Nothing to install, nothing to flash, nothing that can hurt your machine. Every link was opened and checked, and the catalogue is swept for link rot weekly.

Try before you buy

Curious what a PicoCalc, an HP-15C or a PDP-11 actually feels like? Run the real firmware for ten minutes first. Most of these use the original ROMs or bug-for-bug reimplementations.

Learn the machine

Front panels, monitors, BASIC prompts and assembly debuggers with single step. The best way to understand a CPU is to watch it execute, and most of these will let you.

Nothing to break

It all runs client side in WebAssembly or JavaScript. Close the tab and it is gone. Several install as offline apps on a phone, which makes a fine pocket computer in its own right.

See the math move

Fractal zoomers, Fourier epicycles, filter designers, antenna patterns, Game of Life and physics labs. The fastest way to build intuition for a spectrum display or an SWR curve is to drag a slider and watch.

Legal by design

Only sites that ship their own free or licensed software, or expect you to bring files you already own. No ROM archives, no console cores that need copyrighted games.

How to read the badges. Stars are a snapshot of GitHub stars for the emulator's own repository, a rough popularity signal that only exists for open source projects; the rest sort to the bottom of that order. Ease of use is our 1 to 5 rating, where 5 means click and it runs with an obvious interface and 1 means you must bring your own ROMs or disk images and read a manual first. Hover the dots for the reason.

Something missing or broken? Use the Feedback tab on DXEdge. The catalogue lives in a plain JSON file at /emulators/emulators.json if you want to see the raw data.

Picks are the ones we would open first in each category. Consoles that need copyrighted game files are deliberately left out.
